# Контекст

На учебной Linux-машине установлен `ca-web.service`, который сейчас не работает.

# Задача

Самостоятельно диагностировать состояние системы и восстановить сервис.

# Что должно получиться

Сервис активен, переживает штатный restart, а локальный HTTP-запрос возвращает страницу учебного сервиса.

# Ограничения

Не переустанавливать ОС или systemd, не применять массовую очистку и не завершать неизвестные процессы без установления их назначения.

# Что разрешено использовать

CLI Ubuntu, справку `man`/`--help`, документацию, системные журналы и стандартные средства диагностики.

# Что сдавать

Заполненный `diagnostic.md` с командами, значимым выводом, гипотезами, изменениями и доказательством работы.

# Критерии готовности

`ca-web.service` активен; `curl http://127.0.0.1:8080` возвращает ожидаемую страницу; отчет позволяет воспроизвести ход диагностики.
