# Выдача материалов студенту

1. Выполните `make packages`.
2. Проверьте итог: `unzip -l dist/yan-case-XX-*.zip`.
3. Передайте только архив текущего кейса через выбранный учебный канал.
4. Для case 3 попросите студента создать новый пустой GitHub-репозиторий и импортировать содержимое архива одним начальным коммитом. Mentor-репозиторий и его историю не публикуйте.
5. Не передавайте каталоги `mentor/`, корневые документы или `FINAL_REPORT.md`.

Архивы не содержат `.git`, поэтому история закрытого mentor-репозитория студенту не попадет. Перед выдачей case 1 преподаватель устанавливает стенд локально командой `make setup-case1`; архив содержит только постановку и шаблон отчета.
