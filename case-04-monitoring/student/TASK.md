# Контекст

Приложение публикует `/`, `/health` и `/metrics`; Prometheus и Grafana запускаются, но наблюдение приложения еще не завершено.

# Задача

Поднять stack, настроить сбор метрик приложения, подключить Prometheus datasource, создать dashboard минимум с двумя показателями, исследовать учебный инцидент и оформить runbook.

# Что должно получиться

Target приложения UP; dashboard показывает интенсивность запросов и длительность либо другой осмысленный показатель; нагрузка меняет графики; остановка и восстановление отражаются в доступности.

# Ограничения

Только localhost; без реальных секретов, privileged, host networking, Docker socket и чрезмерной нагрузки. Не использовать готовый dashboard.

# Что разрешено использовать

Документацию Prometheus/Grafana, Compose, PromQL, HTTP API и `scripts/generate-load.sh`.

# Что сдавать

Конфигурацию Prometheus, экспорт своего dashboard, `runbook.md`, PromQL и доказательства target UP, нагрузки, инцидента и восстановления.

# Критерии готовности

Три сервиса доступны; Prometheus scrapes приложение; dashboard содержит минимум два показателя, включая request rate/counter и duration либо аналог; runbook воспроизводим.
