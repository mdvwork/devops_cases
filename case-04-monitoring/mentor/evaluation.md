# Оценивание

Каждый критерий оценивается отдельно: **0** — не выполнено, **1** — выполнено частично или с существенной помощью, **2** — выполнено и объяснено самостоятельно.

| Критерий | 0 | 1 | 2 | Балл |
|---|---|---|---|---|
| Функциональный результат | Не работает | Работает частично | Все критерии готовности доказаны | |
| Логика решения | Нет объяснения | Объяснение неполное | Наблюдения, гипотезы и проверки связаны | |
| Самостоятельность | Готовое решение преподавателя | Нужны существенные подсказки | Самостоятельный поиск и проверка | |
| Процесс / Git | История отсутствует или нечитабельна | Есть крупные/неясные коммиты | Небольшие осмысленные коммиты | |
| Документация | Отсутствует | Неполна | Воспроизводима и содержит доказательства | |
| Реакция на обратную связь | Не учтена | Учтена частично | Исправления внесены и объяснены | |

**Максимум: 12 баллов.**

## Учет подсказок

Количество подсказок по каждому виду:

- 0: ____
- вопрос-наведение: ____
- ссылка на документацию: ____
- конкретная команда: ____
- готовое решение: ____

Вопрос-наведение и готовая команда не считаются равноценной помощью. Преподаватель фиксирует вид и момент каждой подсказки.
