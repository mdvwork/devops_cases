# Контекст

Команда передает рабочее FastAPI-приложение в воспроизводимое контейнерное окружение.

# Задача

Создать `Dockerfile`, `.dockerignore` и `compose.yaml`, не изменяя контракт API.

# Что должно получиться

`docker compose up --build` запускает приложение; хостовые запросы к порту 8080 на `/` и `/health` успешны.

# Ограничения

Официальный Python slim image; без лишних системных пакетов, privileged mode, host networking, Docker socket и реальных секретов. По возможности процесс не должен работать от root.

# Что разрешено использовать

Документацию Docker/Compose, логи сборки и контейнера, локальные тесты и диагностические команды Docker.

# Что сдавать

Три созданных файла, исходный код, вывод проверок и краткое объяснение image/container, `COPY`, `WORKDIR`, `RUN`/`CMD`, ports, environment и healthcheck.

# Критерии готовности

Compose config валиден, image собирается, контейнер healthy, `APP_ENV` передается окружением, оба endpoint доступны через `localhost:8080`, после `docker compose down` ресурсы проекта остановлены.
